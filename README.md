# İstanbul Yabancılar İçin Türkçe A1–C1

Учебники **İstanbul Üniversitesi / Kültür Sanat Basımevi** и словарные карточки.

## Книги

| Файл | Уровень |
|---|---|
| `Istanbul_A1_Ders_Kitabi.pdf` | A1 |
| `Istanbul_A2_Ders_Kitabi.pdf` | A2 |
| `Istanbul_B1_Ders_Kitabi.pdf` | B1 |
| `Istanbul_B2_Ders_Kitabi.pdf` | B2 |
| `Istanbul_C1_Ders_Kitabi.pdf` | C1 |

Слова взяты из разделов **KELİME LİSTESİ**.

- `istanbul_words.csv` — всё слово, уровень, транскрипция, русский перевод
- `istanbul_verbs.csv` — только фиилы
- `cards.json` — полный список; в приложении — только глаголы

## Приложение

`android/` — **Petrov Fiiller**: после включения и разблокировки экрана — только турецкие глаголы.

Лицевая сторона: infinitive (gitmek).  
Оборот: таблица Петрова (ben) — gelecek / şimdi / geçmiş × ? / + / −, плюс русский смысл.

Сборка на Termux:

```bash
bash android/scripts/build-termux.sh
```
